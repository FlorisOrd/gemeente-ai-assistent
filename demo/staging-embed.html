Staging embed simulatie

Deze pagina simuleert hoe de widget later vanaf een FXW-server kan worden ingeladen. Lokaal gebruikt de widget dezelfde server voor het script en de API.

Lokale staging-snippet:

<script src="/widget/widget.js" data-tenant="staging" data-api-base="" async></script>

De productievariant zou naar het publieke assistent-domein verwijzen. De API-key staat nooit in deze snippet. De staging tenant gebruikt eigen visuele instellingen vanuit de publieke tenant-configuratie.
