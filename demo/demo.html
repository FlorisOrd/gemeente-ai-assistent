Demo: Gemeente AI Assistent

Deze pagina laat zien hoe een gemeente de assistent later met een enkele HTML-snippet kan toevoegen.

Toekomstige embed-snippet:

<script src="https://example.com/widget.js" data-tenant="demo"></script>

In deze demo laden we hetzelfde widget-script lokaal. De assistent is nog een mockversie: het bericht gaat naar de kleine demo-server, maar er is nog geen echte AI API aangesloten.

De widget laadt publieke tenant-configuratie voor demo, zoals naam, kleur, privacylink, contactlink en toegestane onderwerpen.

Start de server en open deze pagina via http://localhost:3000/demo/demo.html om de volledige flow te zien.
